3. Доработка индивидуального проекта

Название проекта: Сервис ведения дневника.
Выбранная тема: № 81. Основные сущности предметной области — пользователь, запись, категория, дата.
Предметная область: ведение личного дневника с фиксацией событий и размышлений, привязкой записей к пользователю, категории и дате.

На этапе ПР5 консольная объектная модель ПР3 дополнена веб-интерфейсом на Django 5.2. Создан Django-проект diary и три приложения: homepage, categories, entries. Приложение users не создавалось, чтобы не конфликтовать с django.contrib.auth.

Краткое описание доработки: настроена двухуровневая маршрутизация (include и path); реализованы view-функции index, categories_list, category_detail, entries_list, entry_detail; HTML формируется функцией page() с Bootstrap 5.3; страницы читают JSON через классы UserEntity, CategoryEntity, DateEntity и EntryEntity; для несуществующих объектов возвращается код 404; консольное приложение main.py сохранено. ORM, шаблоны и веб-формы не использовались.

Ссылка на Git-репозиторий: https://github.com/Evenysh/service_diary
