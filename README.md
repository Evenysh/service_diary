# Сервис ведения дневника

## Назначение

Приложение помогает пользователю вести личный дневник: создавать записи,
относить их к категориям и фиксировать дату. На текущем этапе проверяется,
можно ли сохранить одну дневниковую запись с заданными параметрами.

## Целевая аудитория

Люди, которые хотят систематизировать мысли, события дня и учебные или
рабочие заметки в одном месте: студенты, специалисты и все, кому удобнее
вести записи в цифровом виде.

## Предметная область

Ведение дневника — это фиксация событий и размышлений с привязкой к дате
и категории. Запись принадлежит пользователю, имеет заголовок, текст,
категорию и дату. В дальнейшем сервис позволит просматривать историю
записей, фильтровать их по категории и дате, а также работать с несколькими
пользователями.

## Основные сущности

- Пользователь — владелец дневника (имя, возможность входа в систему).
- Запись — текст дневника с заголовком и содержимым.
- Категория — тип записи (например, личное, учёба, работа).
- Дата — календарный день, к которому относится запись.

## Основные функции

- Проверка, можно ли сохранить запись на указанную дату (реализовано на ПР1).
- Создание, просмотр, изменение и удаление записей.
- Выбор категории записи.
- Просмотр записей за выбранную дату.
- Регистрация и вход пользователя.

## План развития

На следующих этапах планируется:

- расширение сценариев с коллекциями, циклами и функциями (ПР2);
- объектная модель сущностей (ПР3);
- разработка веб-приложения на Django (ПР4);
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
