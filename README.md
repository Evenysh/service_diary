# Сервис ведения дневника

Консольное приложение для ведения личного дневника:
создание записей, привязка к категориям и датам, поиск и статистика.

## Возможности

- просмотр записей с содержанием и автором;
- поиск записей по подстроке в заголовке;
- проверка возможности сохранения записи;
- создание и удаление записей;
- фильтрация по категории;
- сортировка записей по дате;
- статистика по записям.

## Структура проекта

- `main.py` — точка запуска и меню приложения;
- `entries.py` — работа с записями;
- `validation.py` — проверка и создание записей;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции ввода;
- `data/` — JSON-файлы данных;
- `conftest.py` — конфигурация pytest для корректных импортов;
- `tests/` — автоматизированные тесты.

## Обработка ошибок

- некорректный ввод пользователя (дата, число) обрабатывается в `utils.py` через `try/except ValueError`;
- ошибки при чтении JSON-файлов (`FileNotFoundError`, `json.JSONDecodeError`) обрабатываются в `storage.py`;
- программа не завершается аварийно при некорректных данных.

## Требования

- Python 3.x;
- pytest;
- flake8;
- isort;
- black.

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
pytest
```

## Проверка качества кода

```bash
flake8
```

## Форматирование кода

```bash
black .
```

## Формат данных

Записи хранятся в `data/entries.json` — список словарей с полями:
`id`, `user_name`, `title`, `content`, `category`, `entry_date`, `mood_score`, `is_private`.

Категории — в `data/categories.json`.
